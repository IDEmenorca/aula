# Formació

El programa formatiu s'estructura en **tres nivells**:

<blockquote style="border-left: 4px solid #d4e902; background-color: rgba(212, 233, 2, 0.12); padding: 12px 16px; border-radius: 0 6px 6px 0; margin: 16px 0;">
  <h3 style="margin-top: 0; color: #000;">Nivell Bàsic: Introducció a la cartografia i a la IDE Menorca</h3>
  <p style="margin-bottom: 0; color: #000;">Ideal per a persones que s'inicien en el món dels Sistemes d'Informació Geogràfica (SIG). Aprendràs els conceptes fonamentals de la cartografia, què són les dades geogràfiques i com moure't per l'entorn bàsic de la <strong>IDE Menorca</strong>.</p>
</blockquote>

<blockquote style="border-left: 4px solid #96b002; background-color: rgba(150, 176, 2, 0.12); padding: 12px 16px; border-radius: 0 6px 6px 0; margin: 16px 0;">
  <h3 style="margin-top: 0; color: #000;">Nivell Mitjà: Descobriment de dades i funcionalitats</h3>
  <p style="margin-bottom: 0; color: #000;">Pensat per a usuaris que ja coneixen la base i volen aprofundir en les possibilitats de la plataforma. En aquest mòdul exploraràs en detall el catàleg de dades disponibles, l'ús d'eines de consulta, filtres, anàlisi visual i altres funcionalitats avançades del visor.</p>
</blockquote>

<blockquote style="border-left: 4px solid #596e01; background-color: rgba(89, 110, 1, 0.12); padding: 12px 16px; border-radius: 0 6px 6px 0; margin: 16px 0;">
  <h3 style="margin-top: 0;">Nivell Avançat: Edició, producció de dades i creació de mapes <em>(En desenvolupament)</em></h3>
  <p>Aquest curs estarà enfocat a perfils tècnics i usuaris que necessitin anar un pas més enllà: editar i produir les seves pròpies dades geogràfiques, gestionar capes personalitzades i dissenyar els seus propis mapes.</p>
  <p style="margin-bottom: 0;"><em>Actualment aquest mòdul no està disponible i s'està treballant en els seus continguts.</em></p>
</blockquote>
